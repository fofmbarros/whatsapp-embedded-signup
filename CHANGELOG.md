# Changelog

## 0.1.0

- Initial release of `@fofmbarros/whatsapp-embedded-signup`.
- Headless React component supporting React 18 and 19 with a render-prop UI.
- Embedded Signup v4 and public preview support, including Cloud API signup, WhatsApp Business app coexistence, and account-only completion.
- Typed business-information prefill, signup results, and lifecycle callbacks.
- Facebook SDK loading, signup message validation, and callback error handling.
- Example application with HTTPS development support and a test-only mock backend.
